## 病人快速選擇 v1.6.1

[下載安裝包](downloads/patient-query-v1.6.1.zip) · [原始碼與使用說明](standalone-extensions/patient-query/) · [管理後台](https://pharmacy-device-console.cx760.chatgpt.site)

- 工具列、工具視窗及內部左上角統一使用深綠底、白色病床與小勾勾圖示；登記／鎖定畫面同步更新。
- 圖示提供 16、20、24、32、48、128px，選人、結清及管理流程與權限維持原樣。
- 已使用 v1.6.0 者，可按「工具更新」→「檢查新版」→「更新並重新開啟」。
- 延續自動檢查新版與電腦管理；僅回報電腦識別、版本及管理狀態，不上傳病人、查詢或結清資料。

**從 v1.5.3 或更早版升級需手動更新**：將 ZIP 內 `extension` 檔案覆蓋到瀏覽器原本載入的同一個資料夾，重新載入擴充元件，再完成電腦登記。按「工具更新」→「指定資料夾」選擇相同 `extension` 資料夾，之後即可使用工具內更新，不需 GitHub Token。

驗證：129 項離線檢查通過，實際更新包通過 v1.6.0 更新核心及權限檢核；已核對所有圖示尺寸、引用與檔案完整性。本次未修改後台，未進行真實 Chrome 或院內操作。視窗外框的圖示顯示位置依作業系統而異。

- 取消每月預設藥師操作；跨病房、跨月份及重開草稿保留輸入，已儲存紀錄維持原姓名。讀不到或有衝突時提示手動填寫。
- 報表與 Excel 列印均改 A4 直式。依文字換行調整每頁筆數，保留核章空間、各病房獨立及日期由舊到新。

已安裝 **v1.3.0／v1.3.1／v1.4.0**：工具更新 → 檢查新版 → 更新並重新開啟，沒有新增權限。**v1.2.5 或更舊**：先匯出備份，以 ZIP 覆蓋 Chrome 原本載入的同一 extension 資料夾再重新載入；不要先移除擴充元件。

本次 44 項核心與姓名 DOM 檢查通過。直式列印程式保持 v1.4.0 原樣，沿用先前 37 筆 PDF 的一般文字 2 頁、較長科別 3 頁驗證。[詳細驗證](standalone-extensions/patch-recovery/docs/驗證結果.txt)

姓名定位已由使用者提供的實際開發者工具截圖確認，測試以相同 DOM 結構與合成姓名重現；尚未直接連入院內實機。

只下載公開程式更新，回收紀錄、病人與藥師姓名不傳到 GitHub 或管理後台。後台保留每分鐘裝置回報、最低版本、停用政策及 24 小時離線驗證機制。

## 發布給管理後台的工具索引

後台透過公開的 [updates/catalog.json](updates/catalog.json) 找到工具，再直接讀取各工具的 latest.json 比對最新版，不需要 GitHub Token。

**新增或移除工具時，發布者必須一併更新工具索引**：於儲存庫執行 `python3 scripts/update-catalog.py`，把產生的 `updates/catalog.json` 與新工具一起發布。既有工具改版也建議重新產生索引以更新下載連結；未重新產生時，後台仍會讀取最新版本，但不會把舊版安裝包誤標為新版。

這個流程不授予 GitHub Actions 自動寫入 main 的權限。詳細格式與維護方式見 [索引說明](updates/CATALOG.md)。
