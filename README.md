## 病人快速選擇 v1.6.0

[下載安裝包](downloads/patient-query-v1.6.0.zip) · [原始碼與使用說明](standalone-extensions/patient-query/) · [管理後台](https://pharmacy-device-console.cx760.chatgpt.site)

- 新增工具內自動檢查更新與套用；開啟時及持續開啟每 6 小時檢查，有新版待空閒時提示，按「更新並重新開啟」才更新。
- 以電腦名稱及一次性 4 位數登記碼接入既有管理後台。各工具的最低版本與停用政策獨立，支援共同管理員。
- 結清中收到限制時完成目前一位，再停止後續病人與病房；更新後不會自動恢復結清佇列。
- 只回報電腦識別、工具版本與管理狀態，不上傳病人、查詢或結清資料。

**第一次升級必須手動更新**：將 ZIP 內 `extension` 檔案覆蓋到瀏覽器原本載入的同一個資料夾，重新載入擴充元件，再完成電腦登記。按「工具更新」→「指定資料夾」選擇相同 `extension` 資料夾，之後即可使用工具內更新，不需 GitHub Token。

驗證：129 項離線檢查、32 項後台 API 檢查及後台建置通過。原生資料夾授權、畫面與院內連線仍需在使用者電腦確認；未執行實際病人結清。本包僅含程式碼、合成測試及彙總驗證資料。

## 貼片回收紀錄 v1.3.1

公開更新來源，正式版本為 **v1.3.1**。

[下載安裝包](downloads/patch-recovery-v1.3.1.zip) · [管理後台](https://pharmacy-device-console.cx760.chatgpt.site)

## 這次更新

- 登記碼改成 **4 個數字**（例如 0386），保留開頭的 0。
- 每組有效 10 分鐘、只能使用一次；新碼取代前一組，錯誤 5 次後需重新產生。請一次登記一台電腦。
- 後台加入「共同管理員」：擁有者輸入同事登入 ChatGPT 的 Email，同事就能用自己的帳號管理電腦與使用政策。
- 只有擁有者能新增或移除共同管理員。移除後下一次操作立即失效，管理紀錄會顯示操作帳號。
- 已登記電腦保留原有憑證，不需重新配對。

## 如何升級

已安裝 **v1.3.0**：在工具內「工具更新」→「檢查新版」→「更新並重新開啟」即可，沒有新增權限。

**v1.2.5 或更舊版本**：先匯出完整備份，將 ZIP 內 extension 檔案覆蓋到原本 Chrome 載入的同一個資料夾，再到 chrome://extensions 重新載入。不要先移除擴充元件。首次開啟輸入電腦名稱與登記碼，核對原有紀錄與後台回報。

## 管理機制

只在工具開啟時回報，持續開著每分鐘回報；版本更新每次開啟及每 6 小時檢查。有新版會主動顯示更新視窗，操作中延後。全域與單台政策可設定停用／恢復、最低版本、生效時間及原因，並區分等待接收與已生效。最後驗證後可離線使用 24 小時；已收到的限制持續有效。限制時保留紀錄、更新及完整備份入口。

管理頁與 API 需經授權的 ChatGPT 帳號登入。電腦只回報名稱、識別碼、版本與管理狀態，不上傳病人、回收紀錄、藥師設定或 Portal 帳密。
