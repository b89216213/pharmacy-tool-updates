# pharmacy-tool-updates — v1.3.0 管理版（待啟用）

這個分支保存貼片回收紀錄 v1.3.0 的完整程式與安裝包。正式 main 更新來源仍為 v1.2.5。

管理後台：https://pharmacy-device-console.cx760.chatgpt.site

**目前後台為私人網站，裝置回報入口尚未開通。請先完成入口設定，再將本版安裝到工作電腦。**

## 新增功能

- 首次開啟輸入電腦名稱與後台產生的一次性登記碼。
- 登記電腦數、安裝紀錄數、版本與最後回報時間。
- 全部貼片工具或指定電腦的停用／恢復、最低版本、生效時間及原因。
- 區分政策已設定、等待電腦接收、已生效。
- 視窗開啟時每分鐘回報；關閉後停止。更新檢查維持開啟時及每 6 小時。
- 新作業會被限制；正在處理的作業完成並保存草稿後鎖定。更新與備份入口保留。
- 最長 24 小時離線期限；已接收的停用或升級要求在離線時仍有效。

只回報管理所需的名稱、識別碼、版本及狀態，不上傳病人、回收紀錄或 Portal 登入資料。
管理介面與管理 API 由伺服器確認登入帳號，裝置只能以自己的憑證回報及讀取自己的政策。

## 第一次導入

v1.3.0 增加後台網域連線權限，所以所有較舊版本都需要手動升級一次。

1. 先在舊版匯出完整備份並關閉工具。
2. 將 ZIP 內 extension 檔案覆蓋到原本 Chrome 載入的同一個資料夾。
3. 到 chrome://extensions 按重新載入；不要先移除擴充元件。
4. 後台建立登記碼；工具內輸入名稱和登記碼。
5. 確認原有紀錄仍在，後台出現這台電腦及 v1.3.0。
