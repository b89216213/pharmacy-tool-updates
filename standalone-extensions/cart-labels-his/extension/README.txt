藥車標籤列印 v2.17.0 正式版

安裝與升級
已安裝管理版 2.10.0：開啟「工具更新」，檢查新版後按「更新並重新開啟」。
手動安裝：將本包 extension 內容覆蓋 Chrome 原本載入的同一資料夾，在 chrome://extensions 重新載入。請勿移除原擴充功能，才能保留原本的紀錄、設定與電腦登記。
完成更新後請重新整理 Portal，讓舊的頁面程式退場。
新電腦需完成電腦登記與原安裝資料夾授權。

日常使用
1. 先登入 Portal，再開啟工具；工具依台北時間中午 12 點切換預設早上／下午藥車組合，並自動讀取。手動切換組合也會立即重新讀取。
2. 在兩個組合卡片各自選擇病房。卡片直接顯示已選病房。
3. 核對前兩次交車日期。預設週一至五交車，遇假日或臨時交車請修改日期。是否交車不等於是否有儲存紀錄。
4. 選擇「依交車紀錄更新」或「列印所有在床病人」。相同標籤略過後不占位置；空床只從指定比對日期紀錄與本次完整在床名單推得。資料不完整時不列印，也不判空床。
5. 在預覽格子點選起印位置；「版面微調」可調整上方留白及標籤尺寸，設定會自動儲存。06PE、08PE 每床預設兩張，其他一張，例外最多五張。
6. 「列印並儲存紀錄」在按下時儲存，再開啟列印；取消原生列印視窗仍保留紀錄。「僅列印，不儲存紀錄」不建立新的已儲存病人內容。
7. 「已儲存本次紀錄」顯示在標籤枚數旁。同組病房今日全部已存、重新擷取名單與存檔時相同才顯示；新增、出院、轉床、缺紀錄或未完成擷取都不顯示。

舊版紀錄
沿用原資料夾更新，原本床位紀錄仍可使用。舊版只有日期、病房、床號與病歷號，依這些欄位判斷同一病人；同床換人或轉床須重印。舊紀錄沒有完整名單證明，不會僅因今天曾印過就顯示「已儲存本次紀錄」。
新版完整交車資料在本機保留近 90 天，可在設定下載備份。原本連結的「列印記憶.txt」仍以舊格式同步，可在設定展開「舊版列印記憶 TXT」管理。TXT 不含完整名單校驗資料，重新匯入後須再次儲存，才可能顯示今天已儲存提示。
尚無可靠紀錄的病房照常印在床病人；不憑病房床位表補空床。

連線、後台與更新
Portal 自動選頁、點選查詢處理及切換病房採用貼片回收 1.6.0 的共用機制；病歷號仍透過 Portal「列印病人標籤」擷取。未登入或連線失敗時等待重新連線。
電腦識別、原登記與更新資料夾沿用；管理限制、更新驗證、備份還原與重新開啟流程與目前工具一致。後台只接收電腦識別、版本及管理狀態，不接收病人與列印紀錄。
正式版不含內建虛構病人或院外測試模式。

驗證範圍
已用合成資料與隔離瀏覽器檢查，詳細結果見本次 GitHub 發布驗證文件。未連線院內真實 Portal，未驗證 Windows 原生資料夾選擇器或實體印表機；回院內首次使用仍須核對實際病房名單與列印定位。
