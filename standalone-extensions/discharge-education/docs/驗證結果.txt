出院藥衛教名單擷取工具 v2.9.1
2026-11-03

2.9.1 修正與驗證：
- Chrome 的注入預設會等待 document_idle；衛教 bridge 現在與既有擷取功能一樣設定 injectImmediately。
- 使用持續載入內嵌頁面的 Chrome API 模擬重現 2.9.0 的「讀取 Portal 操作回應逾時」。
- 6 組連線檢查：查詢處理／衛教紀錄分別位於主頁或內嵌頁、錯誤頁面的明確提示、真正無回應時停止且標示階段。
- 操作期限傳入來源頁；即使 Chrome 稍後才執行，逾時的導頁、填欄位、勾處方與送出會先取消。
- 輕量辨識只確認網址，不在尚未就緒時解析整份病人表單。
- 模擬較舊的非同步重繪晚於使用者輸入完成，確認分鐘數保留；填寫草稿以當下快照依序保存。
- 保留既有身份核對、處方完整性核對、送出前持久化紀錄與禁止自動重送。

2.9.0 功能驗證：
- 8 組核心檢查：七天到期／重存不延期／同病人跨批合併／不同日期與序號／已登錄排除／中斷保留／身分與完整性檢查／表單必填與未完成分支／通用表單欄位對應／限定本機儲存欄位。
- 9 項瀏覽器模擬：對象與時間必填、同一病人兩個領藥號與停用處方一次送出、重開排除已登錄、未完成原因、其它對象與語言及學習障礙等動態欄位、自訂摘要、送出回應遺失後禁止重送、重開待核對、人工確認不重送，以及無程式錯誤。
- 使用提供的紀錄，在隔離且禁止連線的頁面核對病人清單、處方清單、衛教表單、送出後狀態與時間的實際 DOM 選取器。
- 目視檢查七天名單與衛教登錄介面，使用合成病人。
- 確認本版未增加 Chrome 權限或變更 CSP，2.8.0／2.9.0 可使用既有更新機制。

既有功能回歸：
- 同日新增病人、新領藥號、同號不同日期、新序號與刪除後重新出現比對。
- 狀態或刷出時間改變不會重列；臺灣時區跨日重設。
- 完整模擬擷取、藥師分配、列印確認、連續新增檢查、空名單再檢查。
- 同日重開、停止擷取、管理停用、次日清除每日比對。
- 65 人含條碼列印完整分頁且不溢出。
- 12 組更新驗證及 7 組管理政策驗證通過。
- 全部 JavaScript 語法檢查通過。

測試使用合成病人、模擬院內伺服器與 Chrome API，並依錄影核對頁面結構；未操作院內真實病人的衛教紀錄。院內實際送出、帳號權限、分頁狀態、實體條碼機及 Windows 資料夾授權仍需現場實測。
待核對項目不會自動重送。處方分頁、資料不完整或身分不符時停止，由使用者核對。
