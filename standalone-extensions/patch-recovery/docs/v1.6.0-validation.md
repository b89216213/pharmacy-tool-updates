## 範圍限制

測試使用隔離 Chromium、合成病人資料、模擬 Chrome API 與 Portal 傳輸；資料夾測試使用 OPFS／記憶體替身。未連線院內真實 Portal，未驗證 Windows 原生資料夾選擇器或實體印表機。本版不含測試引擎或內建假病人，保留正式儲存鍵與備份格式。
