貼片回收紀錄 v1.4.1

資料及操作
- 病人名單查詢沿用既有流程；不執行退藥、銷毀、結清或病人開啟操作。
- 唯讀 readPharmacist 直接擷取 #leftContents #vertical 內 font 的可見文字；若沒有 font 包裝則讀同一個 vertical 欄位。移除登出文字／座標／姓名外觀推測。查詢區同名 ID、隱藏欄位及其他側欄文字不會混入；多個不同姓名則拒絕。
- 使用者提供開發者工具截圖確認實際 DOM：#leftContents > #vertical > font，旁邊 #Logout 是 DIV 包圖片。已重現此結構測試；仍未直接操作院內實機。
- 新增草稿 pharmacistMode，保存手動改名狀態；不改已儲存紀錄，舊草稿保持姓名。
- 舊 defaults 欄位繼續讀寫備份，但介面與新批次不使用每月預設。
- chrome.storage.local 保持 patchRecoveryV1，分病房 recordsByWard，備份 schemaVersion 2，相容 schemaVersion 1。
- 每批原子保存，失敗保留草稿。暫選病人依床號排序，紀錄／列印日期遞增，嚴格限制單一病房報表。

列印
- A4 portrait，10 mm 邊界；十二欄保留病人六項資料、日期、三種劑量、藥師及留白核章。
- 起始每頁至多 24 筆；預覽在字型就緒後依實際文字換行重新分頁，使標題、列、頁碼及合計留在同一張紙。
- Excel 輸出真實 OOXML，A4 portrait、寬度一頁、不執行儲存格公式。

連線與相容
- Portal 權限、背景程式、管理端權限、CSP 與 v1.3.1 相同。
- GitHub 僅下載公開工具更新；管理後台只收到裝置識別、版本及政策狀態。
- 姓名、病人資料與回收紀錄不傳到更新庫或管理後台。
- 正式程式沒有示範模式或預載病人；測試使用合成資料。
