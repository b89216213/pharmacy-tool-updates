貼片回收工具公開更新來源維護（v1.4.1）

固定來源：公開儲存庫 b89216213/pharmacy-tool-updates，main 分支。
更新索引：updates/patch-recovery/latest.json。
程式來源：standalone-extensions/patch-recovery/extension/。
首次安裝包：downloads/patch-recovery-v1.4.1.zip。
舊私人庫的 patch-recovery-updates 分支保留 v1.2.0 歷史，不再作為本版更新來源。

之後發布新版：
1. 修改程式及 extension/manifest.json 的 version，必須遞增。
2. 同步頁尾和 package.json 版本，執行 npm test 及瀏覽器回歸測試。
3. 執行 node scripts/build-update.mjs '本次更新內容'。
4. 將 release/updates/ 下的新版本包及 latest.json 放到公開庫根目錄的 updates/，與新版來源一起提交。
   使用同一筆 Git commit 原子發布；保留已發布的版本包，不可用不同內容覆寫同一版號。
5. 不帶 Authorization、Cookie 讀取公開 raw.githubusercontent.com 來源，核對版本、大小及 SHA-256。
6. 從舊版試行更新，核對版號、原有回收紀錄、草稿與設定。

v1.2.0 → v1.2.1 因變更下載網址與 Chrome 連線權限，必須先以 ZIP 覆蓋同一 extension 資料夾並重新載入。
不要移除擴充元件。v1.2.1 之後在權限未擴大的前提下可透過工具內更新。
更新包只包含 build-update.mjs 白名單中的 18 個程式檔，不掃描使用者資料夾。
不包含病人紀錄、Chrome 儲存資料、憑證或測試輸出；更新器不寫入回收資料鍵 patchRecoveryV1。
公開來源不使用 GitHub API、不使用帳號與憑證，也不送出 cookies 或 referrer。
舊版本機憑證會在首次開啟時刪除，但這不會撤銷 GitHub 帳號上原本建立的 token。
更新包雜湊用來驗證傳輸完整性，發布者信任來自 GitHub 儲存庫權限，並非獨立數位簽章。
未封裝資料夾覆蓋不是跨多檔案的檔案系統原子交易；會保存 journal、每檔驗證並最後寫 manifest。
當整個瀏覽器在更新中突然中止時，可能仍需用原版 ZIP 手動復原。

v1.2.3 僅在工具視窗開啟時檢查：每次開啟立即檢查、持續開著每 6 小時再檢查。未新增 alarms 權限，也未修改 background.js；v1.2.1／v1.2.2 可直接在工具內更新。

v1.2.4 調整「更新可用」按鈕的視覺提示，沿用既有綠色系；只有較新版本可用時套用，更新完成後恢復一般白底。未新增權限，可直接從 v1.2.3 更新。

v1.2.5 在成功檢查到新版時主動顯示更新視窗。同次開啟只提醒一次；查詢、儲存、其他視窗或欄位編輯中會延後，關閉提醒可繼續使用，按更新才套用。失敗檢查與僅有快取不會觸發提醒；沒有修改背景程式或 Chrome 權限。

v1.3.0 增加 management-core.js、management.js，啟用電腦登記、每分鐘回報、最低版本與停用政策。新增後台 host_permissions 與 CSP connect-src，v1.2.5 必須手動覆蓋同一資料夾再重新載入。後台網站已開放裝置連線，管理 API 仍只限管理員登入；本版發布至 main。正式環境配對及院內網路仍須先以單台電腦驗證。
管理員設定存於後台 D1；每台裝置使用獨立憑證，API 不提供裝置讀取其他電腦或修改政策的權限。登記碼為一次性 24 小時有效；續報由後台確認版本與執行狀態。


v1.3.1：登記碼改為四個數字，10 分鐘有效、一次性、最新碼取代舊碼；五次錯誤後需管理員重新產生。已發出的舊長碼可用到原到期時間，已登記電腦保留憑證。後台新增共同管理員名單，擁有者可新增或移除同事的登入 Email；共同管理員可管理電腦與政策，不能再授權其他管理員。首次登入後綁定 Sites 的穩定使用者識別碼。使用者、電腦與既有政策資料保留，資料庫採新增 migration。
v1.3.0 → v1.3.1 沒有新增權限，完整套件已用 v1.3.0 manifest 驗證可直接透過工具更新。v1.2.5 或更舊版本仍需手動導入。


v1.4.0：連線時唯讀擷取 Portal 左側登出控制項下的登入姓名（包含相鄰頁框）；儲存旁可自由修改及重新讀取。移除月預設操作入口，保留舊資料／備份相容。A4 直式預覽以實際行高重新分頁，Excel pageSetup 同步為 portrait。沒有新增權限；v1.3.0／v1.3.1 可工具內更新。發布時必須同步 downloads、updates/patch-recovery、來源程式及公開 updates/catalog.json；不包含 QA 截圖、測試資料、備份或帳密。


v1.4.1：依使用者提供的實際 DOM，姓名改為 #leftContents #vertical 內 font 直接擷取；移除圖片登出定位／座標推測。僅 bridge.js、manifest.json 版號及 tool.html 頁尾改動，其他程式逐檔不變。v1.3.0 以上可工具內更新，既有草稿、姓名修改及直式報表維持原行為。
