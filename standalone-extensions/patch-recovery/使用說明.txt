貼片回收紀錄 v1.6.0

更新既有正式版
1. 點右上角「工具更新」→「檢查新版」→「更新並重新開啟」。
2. 沿用原本已授權的安裝資料夾、電腦登記及本機資料，沒有新增權限。
3. 需要手動安裝時，將 ZIP 內 extension 的檔案覆蓋到 Chrome 原本載入的同一個 extension 資料夾，再於 chrome://extensions 按「重新載入」。不要先移除擴充元件。
4. 更新完成後重新整理院內 Portal 頁面。

首次安裝
1. 將 ZIP 解壓縮到固定位置。在 Chrome 的 chrome://extensions 開啟「開發人員模式」，按「載入未封裝項目」選擇 extension 資料夾。
2. 開啟工具，依畫面授權目前安裝資料夾，輸入電腦名稱及管理員提供的 4 位登記碼。
3. 登入 Portal。工具沿用原系統的查詢頁與登入狀態；需要時可在「其他」內連接 Portal 或返回原系統。

每日登記
1. 「這批回收」上方確認日期。第一次勾選負責的預設病房；以後直接點上方病房按鈕，調整時按「更改預設組合」。
2. 搜尋床號、姓名或帳號；「帳號查詢」可跨病房查完整住院帳號。少數出院病人可切到「已清床」。
3. 點病人卡片，在卡片內填 12.5、25、75 三種貼片的回收片數。可點 0、1、2、3，或輸入其他整數（上限 9999）。0 或空白表示該劑量沒有回收。
4. 再點同張卡片、按「收合」或 Esc 即可收合。點下一位會保留前一位片數；有片數的卡片顯示勾選與摘要。
5. 「清除」經確認後只清除此病人本次待儲存的片數。三種片數全為 0 時，該病人不列入這批。
6. 病人隨整個畫面上下捲動，沒有內層捲軸。下方儲存列顯示這批總人數、片數與可直接修改的回收藥師。
7. 按「儲存紀錄」保存全部病人，同批不同病房各自歸檔。同一人同日已有紀錄會先提醒；另一次收到貼片可選「仍要新增」。
8. 輸入內容自動保留在原電腦，重新開啟可接續。自動保留不等於完成正式登記，仍需按「儲存紀錄」。

補登與日期確認
- 未完成內容重新開啟後保留原日期，不會自動改成今天。日期旁只顯示簡短提示。
- 每次儲存只要有任一筆非今日資料，就會顯示日期與人數確認視窗，即使該日期是手動選擇或上一批已確認也一樣。
- 「返回檢查」或 Esc 不儲存，保留已填內容。
- 「整批改為今天」保留片數與藥師，只更改日期；確認後需再按「儲存紀錄」。
- 「照此日期儲存」可正常補登過去日期；工具跨午夜也會重新檢查。

其他操作與藥師
- 「其他」內提供更新名單、更新整組病房、讀取目前頁、手動補登、重新讀取藥師及 Portal 連線。
- 自動擷取帳號、科別、病房、病室、病床、姓名。請以實際回收的病人帳號核對，避免同床換人或轉床造成誤認。
- 手動補登可輸入六項病人資料、單筆日期、藥師及片數。預設組合以外的待儲存病房會暫時顯示病房捷徑。
- 若原名單有分頁，仍需在原系統翻頁後「讀取目前頁」，或使用完整帳號查詢。
- 連接時自動讀取 Portal 左側登入藥師；可直接自行修改。「重新讀取藥師」會套用目前登入姓名，讀取失敗則保留已填姓名。
- 切換病房、日期與重開工具會保留手動填寫的藥師。已儲存紀錄不受新登入姓名影響。
- 本工具只查詢名單，不執行結清、退藥或銷毀藥帳。

紀錄、列印與 Excel
1. 按「紀錄／列印」，選病房與月份。各病房分開查看、儲存、列印及匯出。
2. 可搜尋、修改、作廢、復原；「歷程」保留修改前的資料。
3. 日期由舊到新排列，較新紀錄在下面。
4. 「列印預覽」後按「列印／另存 PDF」，A4 直式，覆核藥師欄留白核章。建議比例 100%，關閉瀏覽器頁首及頁尾。
5. 每頁表頭重複，依長文字換行調整分頁。「匯出 Excel」產生真正 .xlsx，列印同為直式。
6. 列印與 Excel 包含所選病房、月份所有有效紀錄，不受搜尋條件影響，作廢紀錄不列入。

備份、管理與更新
- 「資料備份」已移到右上角，與工具更新、電腦設定放在一起。
- 完整備份包含全部月份、修改歷程、待儲存內容及預設病房，可合併匯入舊版正式備份。相同紀錄不重複加入，衝突版本會停止匯入。
- 原本的儲存位置與格式保持相容；本版不含假病人，不能匯入測試版備份。
- 本機資料不會傳到 GitHub 或管理後台。後台僅接收電腦識別、工具版本與管理狀態。
- 保留後台停用、最低版本、離線驗證、舊路徑辨識與工具內更新。
- 更換電腦、Chrome 使用者、移除擴充元件或清除資料前請匯出備份。備份與 Excel 請保存於院內核可位置。
- 若連線有問題，可從資料備份頁匯出連線相容性資訊；內容僅包含欄位與控制項結構。

驗證範圍
使用正式版程式搭配合成 Portal 名單、隔離 Chromium、模擬 Chrome API、資料夾授權及更新傳輸驗證。包含資料保存失敗復原、跨病房、日期確認、帳號查詢、藥師讀取、紀錄歷程、列印、備份、後台及更新。
目前無院內真實 Portal 環境，尚未驗證實際 Windows 資料夾選擇器與實體印表機。
