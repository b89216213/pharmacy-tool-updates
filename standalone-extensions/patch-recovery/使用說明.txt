貼片回收紀錄 v1.3.1

安裝
1. 將 ZIP 完整解壓縮到這台電腦固定的位置。
2. Chrome 網址列輸入 chrome://extensions，開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」，選擇解壓縮後的 extension 資料夾（內有 manifest.json）。
4. 把「貼片回收紀錄」釘選到 Chrome 工具列。
5. 登入院內 Portal，進入「查詢處理」，點擴充元件開啟工具。

每日登記
1. 上方確認回收日期，輸入藥師，可按「設為本月預設」。
2. 首次連接後勾選預設病房，可跨院區、數量不限；儲存後自動載入這組在床病人。
   以後直接點左側病房按鈕切換，需調整時按「更改預設組合」。
3. 左側以精簡雙欄呈現更多病人，可連續點選；右側暫選病人依病房、病室、床號排序。
   依實物填寫 12.5、25、75 三種貼片的片數。
4. 片數留白表示該劑量沒有回收。三欄全空的病人需補填或從草稿移除。
5. 按「儲存這批紀錄」一次保存全部病人。
6. 切換病房不會移除已加入的草稿。草稿自動保存，重新開啟可以接續。
7. 同一病人同一天已有紀錄時，會提醒；另一次收到貼片可選「仍要新增」。

病人資料
- 自動擷取帳號、科別、病房、病室、病床、姓名。
- 住院帳號與病歷號不同，工具使用住院帳號。
- 每列「檢視／修改資料」可修改完整資料、單筆日期及單筆藥師。
- 少數已出院病人可切換「已清床」。若原病人轉床或同床已換人，請核對姓名與帳號。
- 可使用完整帳號查詢；必要時手動補登六個欄位。
- 若原系統使用分頁，工具會提示。目前先讀取一頁；在原系統翻頁後按「讀取目前頁」即可選取該頁病人。
- 工具只查詢病人名單，不會送出退藥、結清、銷毀或其他藥帳操作。

每月藥師
- 在「藥師設定／備份」可設定各月份的預設藥師。
- 登記頁改動某筆藥師不會更改整月預設。
- 已儲存紀錄的藥師不會因日後更改預設值而改變。
- 新開啟工具時日期預帶今天。有未完成草稿時保留草稿原日期。

月底列印與 Excel
1. 進入「紀錄／列印」，點選病房，再選擇月份；各病房獨立呈現。
2. 可搜尋、修改、作廢或復原紀錄。修改前資料可在「歷程」查看。
3. 按「列印預覽」，再按「列印／另存 PDF」。
4. 預設 A4 橫向，建議比例 100%，關閉瀏覽器列印的頁首及頁尾。
5. 每頁重複完整表頭，覆核藥師核章欄留白。
6. 「匯出 Excel」會產生真正的 .xlsx 檔，可用 Excel 開啟。
7. 列印與 Excel 僅包含所選病房、月份全部有效紀錄；不受搜尋條件影響，作廢紀錄不納入。
8. 紀錄與列印依回收日期由舊到新排序，較新的放下面；每份報表標示病房。

保存與備份
- 資料按病房分組保存；同批含不同病房時會各自歸檔。
- 升級會自動將舊版紀錄分入所屬病房；不會清除既有紀錄或草稿。
- 完整備份包含全部病房及預設組合，仍可匯入 v1.0.0 的舊備份。
- 資料保存在目前電腦、目前 Chrome 使用者設定檔的擴充元件儲存空間。
- 建議定期使用「匯出完整備份」，保留全部月份、修改歷程、預設藥師及草稿。
- 備份匯入會合併新紀錄；完全相同的紀錄不會重複加入。
- 同一編號若已有不同版本，會停止匯入，避免用舊資料覆蓋現有修改。
- 更換電腦、Chrome 使用者、移除擴充元件、或清除擴充資料前，先匯出備份。
- 更新工具建議覆蓋同一個 extension 資料夾並在擴充元件管理頁按重新載入；不要先移除擴充元件。
- 備份及匯出檔含病人資料，請依院內規範保存。

連線問題
- 確認原系統已登入且位於查詢處理，再點一次工具或按「連接 Portal」。
- 在病人詳細畫面開啟時，工具會使用原系統「重選病人」返回名單。
- 原 Portal 分頁關閉後，重新開啟查詢處理並在該分頁點擴充元件。
- 若仍無法讀取，可在設定頁匯出「連線相容性資訊」。此檔只包含欄位與控制項結構，不含病人內容。

驗證範圍
本版沿用病人快速選擇 v1.5.3 的查詢解析流程，已做合成名單、實際瀏覽器操作、資料保存及匯出測試。
尚未在院內真實 Portal 連線環境執行驗證；首次請核對一批病人的六個欄位與片數。

工具更新與後台管理（v1.3.1）
管理後台：https://pharmacy-device-console.cx760.chatgpt.site
管理後台已開放裝置連線，管理頁仍需管理員的 ChatGPT 帳號登入。請先在一台院內電腦驗證配對、版本回報與原有紀錄，再逐台導入。

已安裝 v1.3.0
在「工具更新」檢查新版，再按「更新並重新開啟」。本版沒有新增權限；已登記電腦不必重新配對。

第一次導入管理功能（v1.2.5 或更舊）
v1.3.0 起增加後台連線權限，因此從 v1.2.5 或更舊版本導入時必須手動升級一次。
1. 在舊版匯出完整備份，關閉貼片回收視窗。
2. 將 ZIP 內 extension 全部檔案覆蓋到 Chrome 原本載入的同一個 extension 資料夾。
3. 到 chrome://extensions 按重新載入。不要移除擴充元件，不要改用另一個資料夾。
4. 在後台用管理員帳號登入，按「新增電腦」產生 4 位數字登記碼；每台電腦使用一組，10 分鐘到期。
5. 開啟工具，輸入電腦名稱及登記碼，按「登記並開始使用」。
6. 確認版號 v1.3.1、原有紀錄與草稿仍在，後台出現電腦名稱、版本及最後回報。
重裝同一台電腦時，在建立登記碼時選既有電腦，避免重複計算電腦數。

4 位數字登記碼
- 只包含 0–9 四個數字，例如 0386；開頭的 0 必須保留。
- 10 分鐘內有效、只能使用一次。全後台只保留最新一組碼；產生新碼會使前一組未使用碼失效。
- 請一次登記一台電腦。連續錯誤 5 次後，請管理員重新產生碼；不同安裝識別碼也共用此上限。
- 已登記的電腦仍使用自己的長憑證續報，不會因登記碼到期或換碼而中斷。

共同管理員
1. 擁有者登入後台，點左側「共同管理員」。
2. 輸入同事登入 ChatGPT 的 Email，按「新增管理員」。
3. 將後台網址交給同事；同事以自己的 ChatGPT 帳號登入即可。系統不會自動寄信。
4. 同事可查看電腦、產生登記碼、改名、停用／恢復與調整最低版本。
5. 只有擁有者可以新增或移除共同管理員，擁有者權限固定保留。移除後，對方下一次讀取或操作即被拒絕。
6. 管理紀錄會顯示操作帳號，方便核對變更。

電腦回報與使用政策
- 開啟工具立即回報，持續開著每分鐘回報；關閉後停止。
- 只回報裝置代碼、安裝識別碼、工具版本及政策執行狀態。電腦名稱在登記時送出。
- 不傳送病人資料、回收紀錄、藥師設定或 Portal 帳密；登記碼與裝置憑證不寫進公開程式。
- 後台可改名、指定單台或全部貼片電腦的最低可用版本、暫停與恢復使用，並設定生效時間及原因。
- 全域限制與單台限制共同作用，單台恢復不會覆蓋全域停用或最低版本要求。
- 後台分別呈現要求的狀態及是否已生效；只有電腦確認套用後才算已生效。
- 已接收的停用或版本要求在離線時仍有效。一般情況最後驗證後可離線使用 24 小時，逾時須連線驗證。
- 收到限制時阻止新的操作；正在執行的作業或編輯視窗結束後保存草稿，再顯示限制畫面。
- 限制畫面保留工具更新、重新連線、電腦設定及完整備份入口；不刪除紀錄。
- 沒有回報不代表已移除或關機。電腦數是已登記的裝置，安裝紀錄可能包含同台重裝或不同 Chrome 設定檔。
- 這是工具內管理；資料夾載入的程式可被本機修改，不等同 Chrome 企業強制管理。

故障處理
院內網路或網站防護阻擋、登記碼失效時，登記不會成功；請聯絡管理員。正式環境裝置配對仍須院內實機確認；雲端環境的直接 HTTP 測試遭網站防護拒絕。
更新中斷無法開啟時，以原版 ZIP 覆蓋同一資料夾再重新載入，不要移除擴充元件。
院內 Windows Chrome 的原生資料夾授權、重新載入與院內連線需實機驗證。
