刷條碼退藥 v1.5.3

安裝／首次升級
1. 完成本次退藥並核對結果。將本包「刷條碼退藥」資料夾內全部檔案覆蓋原本載入的工具資料夾（manifest.json 與 content.js 位於同一層）。
2. 在 chrome://extensions 按此工具的「重新載入」，重新整理院內頁面。不要移除原擴充功能。
3. 開啟工具後，先選擇並授權實際安裝的資料夾。新電腦建議位置為 D:\工作用小工具\刷條碼退藥，這層直接含 manifest.json。
4. 資料夾驗證通過後，輸入電腦名稱與後台提供的 4 位登記碼，等待後台允許使用。
5. 同一電腦已有其他工具時，在後台選擇既有電腦產生新登記碼，以共用電腦識別。
6. 既有電腦請覆蓋原本載入位置並授權該位置。授權與後台驗證都通過後，已開啟的退藥頁面可接續顯示工具。

開啟／關閉
• 點工具列的「碼」圖示開啟工具。已在刷條碼退藥頁面時，工具直接顯示並取代原畫面。
• 在其他頁面開啟時，圖示顯示「待」。自行開啟或切到刷條碼退藥頁面後，工具才自動顯示。
• 待命期間再按圖示可關閉。工具介面顯示時，再按圖示會收合並關閉自動啟用。
• 「回原畫面」會收合目前頁面的工具，方便核對原系統。點工具圖示可再次顯示。
• 自動偵測會尊重手動收合，直到你再次點工具圖示，或進入新的退藥頁面。
• 啟用狀態維持在這次 Chrome 使用期間，背景程式休眠再啟動時可接續偵測。重新啟動 Chrome 後，可再次按圖示開啟。
• 需要首次設定或恢復授權時，會在進入退藥頁後提示。

作業
• 掃描條碼 → 自動全選並按「勾選退藥」→ 能唯一對應的處方直接顯示數量欄位。
• 只有無法唯一對應的重複處方，才按原始序號逐筆選取核對；不依顯示順序或數量猜測。
• 「詳」在點開時才讀取該筆發退藥紀錄。已填數量、藥局選擇會保留，並重新確認原系統欄位與數量。
• 條碼接受英文字母及數字，全形英數會轉為半形；中文、隱藏字元、空格夾在條碼內或超過 18 字不送出查詢，不自動刪除或猜測字元。
• 中文組字與確認候選字的按鍵不觸發查詢。一般掃描器最後的自動換行仍可查詢。
• Chrome 小工具不會強制切換 Windows 輸入法；需要時請切換英文／半形再重新掃描。
• 主要資料字體由 14 縮至 13 px、藥名由 15 縮至 14 px，資料列上下留白縮小；條碼框維持 50 px 高。
• 預設勾選「顯示退藥明細」；「詳」顯示完整發退藥紀錄。覆核資訊保留於次要區塊。
• 手動輸入新退藥量，最後按「確定退藥」才會送出。Enter 只移至下一欄／按鈕。
• 相同處方無法唯一對應時，依原處方序號逐筆讀取、送出並核對數量；中途失敗停止其餘處方。
• 送出後獨立核對總退藥量與餘量；成功後不再逐筆預讀紀錄，下一次點「詳」時取得新紀錄。
• 結果未確認時不可重複送出；回原畫面核對後再重新讀取。

管理與更新
• 後台：https://pharmacy-device-console.cx760.chatgpt.site/
• 管理員可對此工具設定最低版本、停用及指定電腦政策。開啟時每分鐘回報；最後成功驗證後可離線使用 24 小時，已收到的限制仍有效。
• 開啟工具會檢查新版（6 小時內沿用檢查結果），持續開啟時每 6 小時檢查。介面顯示新版提示，按「工具更新」→「更新並重新開啟」。
• 更新僅下載公開程式，驗證檔案雜湊並備份；失敗時還原。更新後請核對並重新整理院內頁面。
• 查詢、退藥、輸入數量或未確認結果存在時，更新會停止。停用政策阻擋下一次操作，已開始的作業仍完成核對，不自動重送。
• 病人、條碼、處方與退藥量不傳至管理後台或 GitHub；管理資料只包含電腦識別、工具版本與政策狀態。

此版以模擬資料驗證；仍需於院內 Windows Chrome 驗證實際頁面及資料夾授權。
