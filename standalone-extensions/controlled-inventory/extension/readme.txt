Portal 管藥盤點 v1.1.0：自動更新與後台管理

首次升級
1. 等所有取歸藥、盤點作業完成。
2. 解壓縮新版，把裡面所有檔案覆蓋至原本 Chrome 載入的工具資料夾；請勿先移除擴充功能。保留相同資料夾與擴充功能 ID，原有本機紀錄與設定才會接續。
3. chrome://extensions 重新載入此工具，並重新整理 Portal。首次新增管理及更新網址權限，請接受 Chrome 顯示的權限提示。
4. 開啟「電腦登記／工具更新」。從 https://pharmacy-device-console.cx760.chatgpt.site/ 取得 4 位一次性碼，輸入電腦名稱與碼。若同一台已有貼片或另一工具，後台請選既有電腦再產生新碼。每個工具需一組新碼，登記後共用同一筆電腦資料。
5. 於工具更新指定目前載入的工具資料夾（含 manifest.json），不是報表資料夾。工具會驗證這確實是載入位置。

後續更新
開啟工具會自動檢查；開著時每 6 小時檢查。找到新版會顯示更新提示；在設定頁按「更新並重新開啟」套用。更新程式寫回已授權資料夾並重新載入，不需要 GitHub 帳號；Chrome 可能再次詢問寫入授權。更新後請重新整理 Portal。
有取歸藥或盤點作業時不能更新，也不會在作業中自動重新整理 Portal。驗證失敗不寫入；寫入中斷會嘗試還原，未完成時下次可選「還原原版檔案」。請保持更新頁開啟。

管理政策
開啟工具時每分鐘回報電腦名稱、工具版本與管理狀態；後台不接收病人資料、藥帳、報表、取歸藥紀錄或數量。工具各自接受最低版本或停用設定；已執行的批次會繼續收集結果，禁止下一批。最後驗證後可離線 24 小時，已接收的限制仍有效。
本版為 Chrome 獨立工具；iPad 腳本與整合工作台未變更。

安裝
1. 將 ZIP 完整解壓縮，保留整個「Portal_管藥盤點工具」資料夾。
2. Chrome 開啟 chrome://extensions，開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」，選擇內有 manifest.json 的資料夾。
4. 重新整理 Portal「特殊藥品管理」頁面，右下角會出現「藥帳帶入盤點」。
這是獨立附加工具，可與 ADC 批次取歸藥工具一起安裝；請等另一工具完成後再操作。

使用
1. 選好目前作業藥局（例如西址住院藥局）。工具沿用你目前的選擇。
2. 按右下角「藥帳帶入盤點」。
3. 選「管1＋管2」或「管1＋管2＋管3」，即開始讀取、填入與送出。

報表規則
• 若正在看今天且時間晚於現在的「結存查詢」，先擷取這個畫面的藥帳，再離開報表。
• 其他畫面或不符時間的報表，會自動查詢今天的下一個整點。例如 20:10 查詢 21:00。
• 日期與時間以臺灣時間（UTC+8）為準。
• Portal 的時段最晚為 23:00；23:00 之後沒有符合「今天且晚於現在」的時段，本次會停止。
• 依完整藥名的「(管1)」「(管2)」「(管3)」判斷；零庫存也會帶入。
• 選管1＋管2時，管3不送出。管4及其他類別均不送出。
• 舊取藥工具的病房／Modipanol 跳過規則不套用在盤點工具。

送出方式
• 擷取全份選定範圍後，依完整藥名對應盤點頁藥碼與單位。
• 先填好全部選定品項，再按一次 Portal 原生「確認」。未選品項保持空白。
• Portal 仍會逐項處理；工具依藥碼核對每一筆回覆，支援不同回覆順序。中間畫面穩定等待 0.05 秒，整批完成後穩定等待 0.2 秒；網路及 Portal 處理時間另外計算。
• 若部分數量與 Portal 最新藥帳不同，該品項列為未完成，不會自動再次確認或改寫數量。其他已成功的品項會保留並顯示，因此可能出現部分成功。
• 未選品項不填 0；留白與數量 0 是不同狀態。
• 執行時會暫時遮住頁面，避免操作衝突。送出前可「取消」；按下整批確認後，會等候所有結果，不提供重複送出或中途撤回。

未完成或連線中斷
• 打開工具可查看每一項「成功」「未送出」「尚未執行」「待查核」。
• 已送出但未確認結果時，不會自動重試。請重新整理，回 Portal 核對該筆盤點紀錄，再按「已回 Portal 查核，解除鎖定」。
• 解除鎖定不會自動執行；再次選擇範圍會建立新的一次盤點，包含先前成功的品項。
• 最近十次結果保留在這個分頁的工作階段，重新整理仍可查看；關閉分頁後不保證保留。

驗證範圍
已依提供的錄製檔核對報表、盤點欄位、錯誤提示與成功回應，並完成離線模擬測試。
尚未在你的院內 Portal 實際執行整批盤點；第一次使用請查看工具結果與 Portal 盤點時間。

檔案不包含帳密、登入憑證或錄製資料；不向外部服務傳送藥帳。
