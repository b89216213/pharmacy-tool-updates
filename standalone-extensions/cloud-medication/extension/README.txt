雲端藥歷整理器 v2.9.1

首次升級：先備份既有設定，將此 extension 內所有檔案覆蓋至 Chrome 原本載入的同一資料夾，在 chrome://extensions 按重新載入，然後重新整理院內頁面。不要先移除擴充功能，以保留既有設定與本機紀錄。Chrome 最低版本 116。

按「電腦登記／工具更新」，輸入管理後台產生的 4 位數登記碼。同機已有其他工具時，後台選既有電腦建立新碼。
後台：https://pharmacy-device-console.cx760.chatgpt.site/

第一次更新設定：工具更新 → 指定資料夾 → 選目前載入、內有 manifest.json 的資料夾。之後開啟工具會自動檢查新版；點更新提示開啟管理頁，檢查新版 → 更新並重新開啟。執行中不會自動覆寫檔案。更新前請先保存需要的內容並關閉工具作業畫面（含嵌入視窗），保留管理頁。更新完成後重新整理院內頁面。

後台只接收電腦識別、名稱、工具版本與政策回報；不接收病人、藥歷、標籤或藥帳內容。停用、最低版本、24 小時離線驗證與其他工具一致。
