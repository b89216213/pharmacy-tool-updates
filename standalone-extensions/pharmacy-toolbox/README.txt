藥局工具箱 v0.1.0 — 空殼版

安裝
1. 將安裝 ZIP 完整解壓到固定位置，例如 D:\工作用小工具\藥局工具箱。
2. 開啟 Chrome 擴充功能頁 chrome://extensions，開啟「開發人員模式」。
3. 按「載入未封裝項目」，選擇 pharmacy-toolbox 資料夾（其中有 manifest.json）。
4. 重新整理 Portal 頁面，右下角會出現四色工具箱按鈕；也能從擴充功能圖示開啟。
5. 開啟工具箱底部「電腦登記／工具更新」，輸入電腦名稱與後台建立的 4 位登記碼。
   同一台電腦已有其他工具：在後台選擇該電腦建立新碼，避免重複建立電腦。
6. 在「工具更新」指定剛才載入、包含 manifest.json 的資料夾，授予更新寫入權限。
   請勿只解壓後搬動、刪除安裝資料夾。

這版可以做什麼
- 中性白色工具箱，左側四色圖示；Portal 與 ihisaw 院內頁面顯示於右下角。
- 四個主選單：病人快速選擇、藥車標籤列印、貼片回收紀錄、出院藥衛教名單擷取。
- 進階工具：ADC 特殊藥品批次取歸藥、刷條碼退藥與 Portal 管藥盤點開關。
- 兩個開關初次安裝均為 OFF，變更後會保留。
- 所有工具入口均標示「尚未接入」；本版切換 ON 只保存設定，不會退藥或盤點。
- 偵測既有病人快速選擇的返回按鈕時，工具箱會向左避讓；窄畫面向上避讓。
- 已接上原有電腦登記、版本回報、後台停用／最低版本控管及 GitHub 更新機制。
- 主選單可瀏覽；日後接入的實際作業必須通過管理驗證。

之後如何接入
- 各工具可以使用各自的視窗，不限定共用同一個作業視窗。
- 本版未加入舊工具程式、資料移轉或舊元件自動停用。
- 請保留原有工具與資料；先不要解除安裝舊擴充功能。

更新
開啟工具箱會檢查新版。新版提示後到「電腦登記／工具更新」套用，完成後重新整理 Portal。
更新使用公開 GitHub 來源，不需要 GitHub 帳號或權杖。
工具箱設定與電腦憑證不會上傳 GitHub；管理後台僅接收電腦、版本與管理狀態。

驗證範圍
已驗證預設 OFF、設定保留、工具來源限制、後台權限範圍、停用及最低版本、更新包雜湊、
資料夾辨識與失敗還原，並以無病人資料的合成頁面檢查介面與返回按鈕並存。
院內正式頁面、實際 Chrome 載入後登記與 File System Access 更新寫入，仍需安裝後實機確認。
