## 驗證

- 使用 GitHub main 原發布版更新核心驗證四個完整更新包，模擬寫入原位置並逐檔比對 SHA-256；額外使用者檔案保留。
- 四套以 Chromium 真實 File System handles 與 IndexedDB，模擬舊巢狀路徑、205 個無關資料夾與同名副本；從四種授權層級皆找到正確位置。
- 測試舊 directory handle 遷移、版本變更、重新載入及瀏覽器重啟、權限恢復、暫時讀取失敗、取消與後台拒絕。
- 刷條碼退藥測試全形／中文組字、40 列處方、重複處方、僅需時讀取明細、保留草稿與藥局選擇、不確定結果停止、未選藥局精確預帶西址住院藥局。
- 刷條碼退藥使用原有內容程式傳訊協調同源 Portal 作業鎖；驗證其他工具占用、續期、過期、僅釋放自己的鎖、拒絕過期與外來要求。無需增加 scripting 或 Portal 首頁權限。
- 退藥待命、手動收合、快速開關、不同頁面、背景重啟與多退藥頁面歧義檢查通過；舊院內頁面提示手動重新整理，不自動導頁。
- 貼片 app.css 與原發布版 1.4.3 完全一致；出院工具包含藍色圖示完整資源。
- 四套儲存庫測試通過；更新測試隨版本遞增，退藥啟用測試改為待命行為，保留原有鎖定、回復與停止條件。
- 四套建置腳本可重現本次更新包與 latest.json，明確包含安裝元件及出院藍色圖示。
- 檢查所有 JavaScript 語法、manifest／HTML 引用、ZIP 與 SHA-256。

測試使用合成資料與目錄；尚未在院內 Windows Chrome 實機執行退藥或衛教登錄。未宣稱所有歷史版本都有更新功能；沒有更新器的舊版仍需一次手動覆蓋，沒有資料夾權限時仍需使用者授權。
