# 管藥工具管理更新 — 2026-11-03

Portal 管藥盤點 1.1.0、ADC 特殊藥品批次取歸藥 1.2.0 加入管理登記與更新。

- 開啟時自動檢查更新，持續開啟每 6 小時再檢查；工具內按鈕套用。
- 工具資料夾的讀寫授權、載入位置證明、SHA-256 驗證、更新前備份、manifest 最後寫入及失敗還原。
- 登記碼 4 碼；同一電腦的不同工具需各產生一次性碼並選擇既有電腦。
- 每種工具分別套用最低版本及停用；作業中延後限制，阻擋下一批，不中斷已送出的數量。
- 更新鎖定跨分頁與 service worker 暫停持續有效；沒有自動重送院內作業。
- 舊有核心、盤點欄位與取歸藥判斷保持逐位元組一致。

驗證：27 組工具模擬檢查 + 32 組後台 API 檢查，後台 production build 通過。未進行 Windows Chrome 原生資料夾授權、院內 Portal 或實機瀏覽器驗證（預覽服務無法連線）。

執行工具測試：`node tests/managed-tools.mjs`。不會連線院內系統；只有合成登記資料。

首次安裝請覆蓋原工具資料夾，Chrome 重新載入並重新整理 Portal；不要移除擴充功能。原本的 iPad 版與整合工作台不在此次更新範圍。
